# CoThink release preparation

Follow [the CoThink release guide](cothink/RELEASE.md) for current build, validation, packaging and publication boundaries.

The fork workflow validates and uploads an Actions tarball artifact. It does not publish npm packages, create GitHub Releases or automatically deploy the legacy viewer. Preserve upstream attribution and LICENSE.

The original argue publishing procedure is retained as [historical reference](upstream/release.md); it must not be used to publish this fork.
