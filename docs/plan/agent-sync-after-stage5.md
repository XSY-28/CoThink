## 路线与取舍

两个可行方向：立即拆成新仓库/新包，或者先在现有仓库建立独立模块与入口。选择后者，先验收职责独立，避免搬迁导致私有包依赖、分发或旧格式问题。模块的物理位置可以暂留原包；独立性的证据是依赖方向、公共操作和外部调用，不是改目录名。

工具复用 Git 存储，不重写 Git 对象数据库；继续采用精确文件范围和保守读写锁，不增加分布式锁、AST 合并、CRDT、任意 shell、动态加入成员或通用 VCS 兼容。
